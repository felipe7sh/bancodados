## 📂 Escopo dos Estudos

Este repositório armazena scripts SQL (`.sql`) estruturados para fins acadêmicos e projetos práticos. Os códigos abordam tópicos essenciais como:

*   **D複 (Data Definition Language):** Criação de bancos de dados, tabelas, definição de chaves primárias (PK) e estrangeiras (FK).
*   **DML (Data Manipulation Language):** Inserção (`INSERT`), atualização (`UPDATE`) e exclusão (`DELETE`) de registros.
*   **DQL (Data Query Language):** Consultas simples e complexas utilizando filtros (`WHERE`), ordenação (`ORDER BY`) e agrupamentos (`GROUP BY`).
*   **Relacionamentos:** Modelagem e junção de tabelas através de comandos `JOIN` para relacionar entidades do mundo real (como produtos, clientes e vendas).

*Novos scripts e modelagens são adicionados à raiz do repositório conforme avanço nos meus estudos de banco de dados.*

## ⚙️ Como Utilizar os Scripts

Para rodar e testar os scripts contidos neste repositório, siga as instruções abaixo:

### Pré-requisitos
*   Ter um Sistema Gerenciador de Banco de Dados (SGBD) instalado, como **MySQL**, **PostgreSQL**, **SQL Server**, ou utilizar uma ferramenta como o **DBeaver** / **XAMPP**.

### Passo a Passo
1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Executar o Script:**
   * Abra a sua ferramenta de banco de dados de preferência.
   * Conecte-se ao seu servidor local.
   * Abra o arquivo `.sql` desejado contido na pasta clonada.
   * Selecione os comandos e execute-os para criar as tabelas e popular o banco de dados.
